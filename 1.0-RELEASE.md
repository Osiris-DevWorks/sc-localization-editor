# Overview

So I like many SC fans, I found Star Citizen's information in game to be lacking. This is totally understandable as updating documentation on an alpha is an always-moving target.
That said, I was inspired by the work of community folks like Mr. Kraken to tackle this issue and take it up a notch. I wanted smarter item, mission, and journal descriptions so I created Smart Citizen.
With my tool, you will get the option to apply the following enhancements out the box:

## FPS Weapons Info Enhancements

Appends combat stats to FPS weapon descriptions:
- DPS
- fire rate
- range
- per-shot damage.

## Ship Info Enhancements 

Appends flight and combat stats to ship descriptions: 
- SCM speed 
- hydrogen fuel
- quantum fuel
- cargo capacity
- full weapon loadout
- armor damage multipliers (physical / energy / distortion / thermal).

## Ship Weapons Info Enhancements 

Appends combat stats (DPS, fire rate, range, damage) to ship guns and turrets from size 1 through capital, and tags missile/bomb names by size and type.

- Missile example: `Arrester III [S3-IR]` — size 3, infrared tracking.
- Bomb example: `500SCB Cluster [S5]` — size 5 bomb.

## Ship Component Info Enhancements

Appends to the item info: 
- stats to shield, cooler, power plant, and quantum drive descriptions
- shield HP, power draw, cooling rate, regen, and similar per component type.

## Mission Info Enhancements

- Annotates mission titles and descriptions with reward and difficulty data.
- Title tags: `[BP]` when the mission always rewards blueprints; `[BP?]` when only some variants do.
- Description adds three blocks: `MISSION DETAILS` (spawn counts, difficulty, flags, XP), `POTENTIAL BLUEPRINTS` (item pool, split by system where it varies — e.g. `[Stanton]`, `[Pyro RegionA, Pyro RegionB]`), and `ITEM REWARDS` (guaranteed item payouts).
- Declarative patch system works around known CIG-side data bugs — for example, the Jorrit Dossier P2M4 that makes sure you see the mission info for the Energy Anomaly and Power Usage missions despite this [bug](https://issue-council.robertsspaceindustries.com/projects/STAR-CITIZEN/issues/STARC-203588).

## Journal Entry Enhancements

Adds crafting and mining data to journal entries. 

- Mining guide entries include mineral locations and crafting cross-references.
- Commodities used in crafting get a `[CF]` name tag and a `BLUEPRINT DATA` block listing every blueprint that uses them.
- Example: aluminum's journal entry shows every blueprint that calls for it.

On top of that, you will have access to the String Editor and all its features:

## Filters

The editor's main view is a sortable table of every localization key in the game (87,000+ on LIVE 4.7). Filter by:

- **Category** — Ships, Ship Items, Missions, Gear, Commodities, Journal, Other
- **Status** — modified / unmodified / all
- **Favorites only** — one click to narrow to starred ships
- **Free text** — searches across default + current + custom values

Plus there's a filter row under every column header for fine-grained narrowing within an already-filtered set. Click any column header to sort.

## String Editing

Double-click any cell in the Custom Value column and type to edit. It will auto-save. This allows you to rename anything in the game that has a localization string. 
I've used this personally to rename Hephastenite to "Heph" so it doesn't block the mining quality numbers, and I've also renamed some wikelo ships that have bad names,
such as the Wikelo Hornet that doesn't indicate that the reward is actually the Super Hornet.

If you've got an existing INI from somewhere else (another tool, a community pack, a backup you made before uninstalling) you can import it and a conflict dialog lets you resolve overlaps key-by-key — keep your current value, use the imported one, append, prepend, or write a custom merge.

Apply to Game writes the merged result to your `global.ini` and makes a timestamped backup of the previous version first. Up to 5 backups are kept, and Restore Backup rolls you back to any of them with one click. If something ever looks wrong after an apply, you're one button away from where you were.

## Favorite Ships

Star a ship in the table and it gets a configurable prefix (default `*`) prepended to its name. This will cause your favorite ships to sort to the top of the ASOP.
