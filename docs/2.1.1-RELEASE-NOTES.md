# Smart Citizen 2.1.1

> ⚠️ **Heads-up if Windows blocks the installer:** Smart Citizen is not yet code-signed, and Windows 11's **Smart App Control** (SAC) blocks unsigned installers, Properties → Unblock does **not** help with SAC. To install:
>
> 1. Open **Settings → Privacy & security → Windows Security → App & browser control**.
> 2. Click **Smart App Control settings** and set it to **Off**.
> 3. Run `SmartCitizen-2.1.1-Setup.exe` and finish installation.
> 4. After install, you can return to the same screen and turn Smart App Control back on if you'd like.
>
> A code-signing certificate would remove this friction permanently. Smart Citizen is a free side project, so signing will only happen if community donations cover the recurring cost, **or** if Smart Citizen reaches enough adoption to qualify for a free certificate through the [SignPath Foundation](https://signpath.org/) open-source endorsement program. Until then: SAC-off install, SAC-on after.

## 2.1.1 hotfix

Hey Smart Citizens! 2.1.1 is a hotfix for the new Mission Titles routes, based on the first round of 2.1.0 testing reports (#200). If you're on 2.1.0, please update: the route titles it generates have display problems in mobiGlas.

What's fixed:

- **The route arrow renders now.** mobiGlas has no glyph for the `→` character, so it drew a box. The Arrow option is now a plain `->`.
- **No more raw "Locationname" text.** Routes now use the full address by default (the same form mission bodies use), which always displays. The short-name option is still there in the Tag Builder if you prefer it.
- **Destinations stopped going missing.** Hauls like Everus Harbor to Port Tressler showed only "from Everus Harbor". The generator now finds the drop-offs the game hides one level down in its data.
- **Multi-stop hauls list their drop-offs.** A single-pickup haul with several stops reads like `ARC-L2 Lively Pathway Station > Port Tressler, Baijini Point`.
- **More missions get routes.** Multi-pickup hauls and the "Local Shipment Route" courier contracts now carry them too.
- **New: Shorten original titles.** An optional Tag Builder toggle trims stock-title boilerplate and abbreviates cargo-grade sizes ("Senior Rank - Direct Medium Cargo Haul" reads "Senior - Direct M"; Extra Small reads XS) so the route and tags fit the contract list.
- **New: Route shape arrow.** An optional arrow style that encodes the route shape in the glyph: `->-` one pickup to one drop, `->=` one to many, `=>-` many to one, `=>=` many to many.

After updating, **regenerate enhancements and apply** (one button in Simple mode) to get the corrected titles into your game.

One honest limit: FTL courier and some Covalex delivery titles stay plain. Those missions don't expose their locations to titles in the game data, and our in-game testing showed that forcing tokens onto them prints garbage. We'd rather give you no route than a broken one.

The full 2.1.0 notes follow, everything below shipped days ago in 2.1.0 and is included here.

## Headline

ODW coming to you with the Smart Citizen 2.1.0 release! This one is packed with new features suggested by our awesome fans and contributors on our Discord.

## New features

### Simple Mode

Some users find prior versions of Smart Citizen a bit intimidating to use. In this version, we've added **Simple Mode**, which provides a simple, two-button interface for applying the default (or user-configured) enhancements. One button applies these enhancements, the other switches you to Advanced mode. Pick your default at install; switch anytime.

### Blueprint Ownership Tracking

Track what blueprints you own so when you look at mission blueprint rewards, you can tell which ones you have and which you don't. The Smart Citizen interface for selecting these supports **multi-select** to speed up the process of selecting your blueprints. Owned items get a star in a new **Owned** column, and blueprint-title / blueprint-description filters help you find them fast.

### Customizable Hauling / Delivery / Courier Mission Names

A new **Mission Titles** tab in the Tag Builder uses the same tag engine to **prepend, append, or replace** mission titles so they include the start and end destinations. A hauling run reads like `Area18 > Lorville - <original title>`, with configurable arrow, separator, and location detail, and a live preview.

### Enhanced Crafting Commodity Info

The Commodity Tag Builder has been enhanced to insert short codes for the blueprints a commodity is used for. For example, if activated, instead of "Beryl" you'll now see **"Beryl [CF | F P Q | Collection]"**, with F, P, and Q standing for FPS weapons, Powerplants, and Quantum Drives. Like most other Tag Builder elements, you can choose short, medium, and long-form codes for these blueprint categories. (The individual commodity descriptions now mirror the journal's crafting formatting too.)

## Also in this release

- **Spanish is live (#182).** Español now shows in the language dropdown, with the interface translated by **Thord82**. Under the hood, `ui.json` moved to a human-vs-AI leaf format so we can track exactly which strings are real human translations and which are placeholders awaiting one.
- **FAQ tab (#152).** The questions we hear most, answered right in the app: what files get touched, whether you can get banned, the Windows unrecognized-app warning, and how to undo changes.
- **ASOP ship numbering (#142).** Put a number in the new **#** column on a favourite ship and it reads like `01-ShipName` in-game, so your ships sort in the exact order you want at the ASOP terminal.
- **Stats above or below (#153).** Flip a stat block to the top of a description instead of the bottom.
- **`[ACE]` / `[ACE?]` title tag (#158)** for missions that spawn an ace pilot.
- **"None" separator for commodity tags (#97 follow-up)**, so you can choose to run the flags together on purpose.
- **Safer edits (#172).** `user.ini`, every hand-entered edit you make, now gets rotating backups (up to 5, taken automatically before each change), with a **Restore user.ini** button in the Config tab. Smart Citizen also **warns when your data folder lives inside OneDrive**, the setup that has quietly emptied `user.ini` for some users, and offers to move it somewhere local.

## Fixes

- **Restore Backup crash** from a stale load call, fixed (#185)
- **Blueprint dropdowns**: Class / Size / Grade menus work, the "Other" type no longer lists armours, and dropdowns don't catch the scroll wheel as you pass over them (#195, #196, #197)
- **Salvage contracts** honor the Hostiles toggle and stop listing hostiles that don't match the mission (#162, #163, #165)
- **Owned column** sorts owned-first instead of by key (#189)
- **Earnable quantum drive names** get tagged correctly by mirroring `_SCItem` to the capital key (#190)
- **Meaningless typeless `[S1-A]` tag** dropped from blueprint lists (#160)
- **"Unknown" spawn bucket** no longer renders in mission details (#187)
- **Mission-header emphasis** now reads as Underline / Blue text instead of the confusing EM3 / EM4 labels (#164)
- **Switching the SC install path** to a different drive persists correctly (#150)
- **Simple mode window** opens compact and at a sensible minimum size (#180)

## Known issues

- **Handle security threat missions can still show the wrong hostiles (#186).** We reworked the handler-spawn fallback this cycle, and the hostile list changed, but a tester confirmed it's still not fully correct on the 2.1 release candidate. Rather than hold the whole release on it, we're **shipping with the fix in progress and carrying #186 forward** into the next cycle. The issue stays open; if you see a mismatched hostile list on a security-threat mission, add a note there.
- **Some blueprint names don't match their changed values (#194).** A deeper inconsistency between a ship-weapon's standalone tag and its re-tag inside blueprint lists. Deferred to a dedicated fix next cycle.
- The upstream CIG data-bug workarounds documented in **Help → Known Issues** still apply (e.g. the Jorrit Dossier mislabel); those live in CIG's own data and we can only work around them.

## Under the hood

- The test suite grew to just under 1,000 (993 passing) as the new features landed with coverage.
- The apply button is now labeled **Apply Enhancements** everywhere (it was "Apply to Game" / "Generate & Apply to Game"); docs, dialogs, and the guided tour all match.
